# AGENTS.md

## Project purpose

This repository is being prepared for a simple children’s learning webapp and game about AI workflows. The intended learning concepts are a goal, specialized work, dependencies or handoffs, and validation of a result.

OrcMe is a conceptual reference for those workflow ideas. Do not copy OrcMe source, assets, names, or other material: its referenced package is `UNLICENSED` unless reuse permission is explicitly obtained.

## Development sequence and boundaries

Update this file before product implementation. After the product scope is defined, use the repository’s normal GitHub issue-based development process; reconcile existing open issues before creating duplicate work.

The repository does not yet contain an application stack, routes, gameplay implementation, or test harness. Product and technical choices that are not yet defined—including target age, gameplay details, accessibility, privacy, platform, and hosting—must be decided and documented rather than assumed.

Preserve the existing `.env` boundary: it contains extension variables and does not need to be read. Do not commit it.
